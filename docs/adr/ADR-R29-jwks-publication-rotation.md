# ADR-R29: JWKS 公钥发布端点与验签端热轮换闭环

日期: 2026-11-17
状态: 已采纳
关联: ADR-R19（签发私钥移出 API 进程）、包 B4、决策 4（RS256 JWT）

## 背景与问题

ADR-R19 之后，签发与验签的密钥边界已经闭合：签发私钥只在 issuer 进程，
API 进程只持有公钥（`IDENTITY_PUBLIC_KEY_PEM` 或 `IDENTITY_JWKS_FILE`）。
但公钥的**分发**还缺一半：

1. **无发布端点**：外部验签方（外部工具适配器、第三方消费方）没有标准途径
   拿到公钥集——`packages/identity/jwks.py` 的注释里写着"将来也可来自
   HTTP 端点"，但该端点不存在。
2. **验签端轮换需要重启**：`get_public_key_store()` 与
   `_principal_authenticator()` 都是 `lru_cache` 单例，JWKS 文件更新后
   验签端感知不到；轮换只能靠重启。而"签发端追加新 kid、验签端整体替换"
   的多 kid 轮换机制在代码注释里早已声明，却没有运行时承载。

缺口性质：这不是安全问题（公钥可公开），而是**轮换闭环的最后一公里**——
没有它，密钥轮换是一次需要停机窗口的运维事件；有了它，轮换是文件操作。

## 决策

### 1. 发布端点：`GET /.well-known/jwks.json`

- 文档来自 `get_public_key_store()`——**与验签路径同一来源**。这是本决策
  的核心约束：不存在"发布的公钥"与"验签的公钥"两个版本，热轮换后端点
  无需任何额外动作就自动反映新公钥集。
- 不鉴权（公钥本身可公开分发，RFC 7517 的标准暴露形态），`include_in_schema=False`
  （基础设施元数据端点，与 /health、/metrics 同类，不进业务契约面）。
- 标准 HTTP 缓存语义：`Cache-Control: public, max-age=300` + `ETag`
  （对规范化 JSON 体做 SHA-256）+ `If-None-Match` → 304。
- 该路径加入限流豁免集合（原 `_PROBE_PATHS` 更名为
  `_RATE_LIMIT_EXEMPT_PATHS`）：外部验签方在令牌风暴期间高频拉取 JWKS，
  被限流会把"密钥分发正常"误判成"密钥源失效"，放大而非缓解故障。

### 2. 验签端热轮换：文件来源 + 周期重读

- 新增配置 `IDENTITY_JWKS_REFRESH_SECONDS`（默认 `0` = 关闭，不改变
  现有部署行为）。
- `> 0` 且验签公钥来自 JWKS 文件时，API 进程 lifespan 启动轮询任务：
  每 interval 重读文件，文档变化即**整体替换**验签公钥（多 kid 共存）。
- 实现收敛在 `deps.reload_verification_keys_if_file_changed()`：候选仓储
  在缓存外构建（文件损坏 → 异常抛出 → 缓存未动 → 验签继续用旧密钥，
  fail-closed 且无损），文档未变化是幂等 no-op，变化时**两个缓存同时
  失效**——只清公钥仓储、留下捕获了旧仓储的认证器，轮换等于没发生。

### 3. 刻意不支持的场景

- **PEM 环境变量来源不支持热刷新**：PEM 来自环境注入，环境级轮换本来就
  伴随进程重启；强行支持会制造"文件盖过 PEM"的第二条公钥来源，破坏
  `get_public_key_store` 的来源优先级语义。刷新函数对此直接返回 False。
- **不自动拉取上游 JWKS**：验签端轮换的触发源是签发端追加 kid 的文件，
  不是定时抓取某个 URL。多一层"验签端去别处拉公钥"就多一层需要信任和
  可用性保障的依赖；文件挂载（secret volume）已经解决了分发问题。

## 后果

- 正面：密钥轮换从"停机运维事件"变为"签发端追加 kid → 等待拾取"的
  文件操作；外部验签方获得标准公钥分发通道。
- 负面：多一个后台任务与一个公开端点（均默认安全：任务默认关闭，
  端点只发公钥）；轮询间隔内存在轮换感知延迟（`max-age=300` 同量级，
  与"旧 kid 共存期"设计一致，不构成正确性问题）。
- 测试：换装语义（双缓存同时失效）与端点同源性有专门测试覆盖。

## 验证

- `tests/unit/test_identity_jwks_rotation.py`：守卫条款、幂等、双缓存换装。
- `tests/integration/test_jwks_endpoint.py`：同源一致性、缓存头、304 语义。
