ADR-R46 版本索引（append-only，只追加不修改）
================================================================================
用途
--------------------------------------------------------------------------------
本文件是 ADR-R46 的唯一版本指认处。把「版本指纹」从正文里拿出来，
避免「改了正文 → 正文里写的哈希失效 → 没人知道哪份是真的」这类自相矛盾。
正文不得内嵌自身哈希。

规则（三条，不可协商；承继 ADR-R40-VERSION.txt / ADR-R44-VERSION.txt / ADR-R45-VERSION.txt）
--------------------------------------------------------------------------------
R1  只追加。任何一行一旦写入，不得修改、不得删除。发现记错只追加
    「CORRECTION」更正行，写明被更正行号与原因。
R2  正文不内嵌自身哈希。ADR 正文只写「指纹见本文件」。
R3  哈希必须带口径：
      - git blob SHA1：git 对仓库内字节计算（core.autocrlf=true 下归一化为 LF）；
      - 文件 SHA-256：工作区磁盘字节（Windows 上受 core.autocrlf=true 影响可能为 CRLF）。
    两者不得混用，也不得只给其中一个而不说明是哪个。
