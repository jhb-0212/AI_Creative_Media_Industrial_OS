## 口径提醒

- 本闸门只回答「**有没有被纳入**」，不回答「纳入的约束够不够强」。
  三列外键仍只保「目标真实 + 租户组织一致」，**不保本行 project 与父行相同**。
- C8 与 `acceptance_ledger.py` 有重叠但不冗余：台账判「这一行闭环了吗」，
  本闸门判「台账这张清单完整吗」。前者全绿而后者红，正是 `episodes` 那一类。
- 豁免的前提是 SQL 不是文字：前提失效（如父行复合外键被删）时 C5 会变红，
  而不是等到下一轮人工复核。
